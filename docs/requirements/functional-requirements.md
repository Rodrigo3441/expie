## Functional Requirements

| ID	| Functional requirement |
|-------|------------------------|
| FR-01 |	Browse directories and subdirectories.|
| FR-02 |	Display files and their information.|
| FR-03 |	Download files.|
| FR-04 |	Upload files from a client device.|
| FR-05 |	Create directories.|
| FR-06 |	Rename files and directories.|
| FR-07 |	Move files and directories.|
| FR-08 |	Delete files and directories.|
| FR-09 |	Download an entire directory as a ZIP archive.|
| FR-10 |	Upload multiple files simultaneously.|
| FR-11 |	Upload directories while preserving their internal structure.|
| FR-12 |	Display file names, types, sizes and modification dates.|


## Out of scope
| Old ID | Requirement | The reason it was removed |
|--------|-------------|---------------------------|
| FR-12 (old) | Select and move multiple files and directories. | Removed because moving multiple resources simultaneously is out of scope. Individual move operations remain supported. |
| FR-14 (old) | Display hidden files and directories using visually distinct icons. | Removed because visually distinguishing hidden files is no longer a requirement. Hidden files can still appear in directory listings. |
