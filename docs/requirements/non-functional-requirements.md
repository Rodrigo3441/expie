## Non-Functional Requirements

| ID | Category | Requirement |
|---|---|---|
| NFR-01 | Accessibility | Interface usable on computers and mobile devices. |
| NFR-02 | Deployment | Must run on a Linux server. |
| NFR-03 | Configurability | Storage location must be configurable. |
| NFR-04 | Security | Filesystem operations must not escape the configured storage boundary. |
| NFR-05 | Network | Initial access restricted to the trusted LAN, without authentication. |
